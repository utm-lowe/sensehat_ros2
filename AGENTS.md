## 📦 Project Overview
**sensehat_ros2** is a ROS 2 package written in pure Python. It provides ROS‑2 interfaces for the Sense Hat v2 hardware:
- Publishes sensor data (temperature, humidity, pressure, IMU, etc.) as ROS topics.
- Subscribes to topics to control the 8×8 LED matrix, allowing users to display images or text from ROS messages.

This package enables seamless integration of the Raspberry Pi Sense Hat into ROS 2‑based robotic applications, supporting both sensor streaming and LED visualisation.
